# Dev B — Phase 8: Approvals inbox matches the chain

**Design:** [../phase8.md](../phase8.md)

- Manager inbox: owned-project requests/changes in `Submitted` only.
- Admin inbox: `PendingApproval`, plus `Submitted` tickets with no project (Admin-only step).
- Copy on the row: “Waiting on manager” vs “Waiting on admin”. Do not show a final Approve button to a Manager.
