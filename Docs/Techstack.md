### 1. Frontend (UI/UX)
* **Core Framework:** **React (via Vite)**
* **Styling & Components:** **Tailwind CSS + shadcn/ui**
* **State Management & Data Fetching:** **React Query (TanStack Query) + Zustand**
* **Routing:** **React Router**

### 2. Backend & Database (BaaS)
* **Platform:** **Supabase**
* **Database:** **PostgreSQL (via Supabase)**
* **Authentication & Security:** **Supabase Auth + Row Level Security (RLS)**
* **Real-time:** **Supabase Realtime**

### 3. Infrastructure & Deployment
* **Frontend Hosting:** **Vercel**
* **Backend Hosting:** **Supabase Managed Cloud**

### 4. Third-Party Services & Automation
* **Transactional Emails:** **Resend**
* **Automation Compute:** **Supabase Edge Functions**
* **Cron/Scheduled Jobs:** **pg_cron (Supabase extension)**
