# Tech Context

**Ecosystem:** TypeScript Monorepo (pnpm)

**Frontend:**
- Framework: React (Vite)
- Routing: React Router
- UI/Styling: Tailwind CSS, Shadcn UI
- State Management: Zustand

**Backend:**
- Framework: NestJS
- Runtime: Node.js

**Database & Auth:**
- Database: PostgreSQL
- ORM: Drizzle
- Auth: Supabase Auth (Targeted, currently using local mock fallback)
