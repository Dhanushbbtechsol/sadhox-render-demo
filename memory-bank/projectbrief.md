# Project Brief

Sadhox is a production-oriented IT Service Management (ITSM) and Asset Management web app. It implements core ITIL workflows for End Users, Agents, and Admins in one platform.

## Product goals
- Unified portal for incidents, problems, service catalog/requests, changes, assets, and knowledge.
- Strict Role-Based Access Control (Admin, Agent, EndUser).
- Real-time comments, SLA automation, transactional email, audit trail, and deployable NestJS + React stack.

## Delivery model
- Four parallel tracks (Dev A–D) over ~5 weeks (Phases 1–5), merged into integration branch `Audit`.
- Requirements authority: `Docs/PRD.md`, `Docs/FRD.md`, coverage: `Docs/Phase/coverage-matrix.md`.
- Claude/AI handoff summary: `Docs/STATUS.md`.
